# iClock 1.03 for Windows

Download **`iClock-1.03-windows.zip`** (or standalone **`iClock-1.03-windows.exe`**), extract it, and run `iClock.exe`. No installer or administrator privileges are needed.

## What's Changed

- **Reliable Default Hotkey (`Ctrl+Shift+T`)**: Replaced problematic Space hotkey with `Ctrl+Shift+T` to avoid system hook capture and IME conflicts. Includes seamless automatic configuration migration for existing users.
- **Smart Hotkey Fallback & Conflict Detection**: Intelligent fallback cascade when configured hotkey is occupied, with clear notification and tray status feedback. Added real-time hotkey conflict detection and standalone function key (`F1`-`F12`) support in settings.
- **High-DPI Optimized Tray Icon**: Redesigned tray icon with optimized visual weight (micro-boss geometry) ensuring crisp, legible rendering across all Windows scaling factors (100%, 125%, 150%, 200%) without appearing undersized.
- **Tray Left-Click Action**: Directly start or pause the countdown with a single left click on the tray icon.
- **Screen Centering & Dialog Polish**: Guaranteed screen centering on active display for NoticeDialog, WelcomeDialog, and SettingsDialog. Redesigned WelcomeDialog with clean layout, prompt icon, and prominent hotkey badge.
- **Enhanced History Tracking & Statistics**: Added sequence number column (`#`), actual duration column, and bottom summary status bar to today's countdown history with auto-stretching full-width layout.
- **Refined Countdown Defaults**: Countdown format defaults to `MM:SS`, and countdown display defaults to horizontally centered and 60px from the screen top.

## Requirements

- Windows 10 or Windows 11 (also supports Windows 7 SP1 / 8)
- .NET Framework 4.x
