## 🌟 What's New in v1.07 / 主要更新内容

### 🧭 Streamlined Tray Menu & Terminal CLI Guidance in AI Collaboration Tab / 托盘菜单瘦身与终端指令引导
- **Eliminated Redundant GUI Dialog (彻底移除冗余图形化命令行窗口)**：删除了 185 行的 `CliHelpDialog` 独立窗口代码，标准化终端帮助为 `iclock -h` 与 `iclock --help`，命令行作为单一事实来源。
- **Streamlined Tray Context Menu (托盘一级菜单瘦身)**：移除了系统托盘菜单中相对低频的“命令行 (CLI)...”项，大幅降低认知干扰。
- **Consolidated Terminal CLI Tip in Settings Tab 2 (在 AI 协作设置底部加入终端指引)**：在 Tab 2 底部单行合并呈现引导提示（`提示：支持在终端直接运行 iclock -h 查看脚本控制指令，或执行 iclock --install-cli 写入 PATH 环境变量。` / `Tip: Run iclock -h in terminal for CLI & script automation, or run iclock --install-cli to add iClock to User PATH.`），通过自定义 `StyledTipLabel` 控件实现依据窗口宽度的智能断句换行，关键词（`iclock -h` 和 `iclock --install-cli`）以 **蓝色斜体** 醒目渲染。
- **Optimized Tab 2 Vertical Spacing & 3-Row Agent List (优化智能体列表高度)**：微调 `panelAgentBox` 高度至 114px，完整容纳规整 3 行智能体卡片，彻底避免卡片底沿截断，释放纵向视觉空间。

### 💬 Desktop Quote Alt + Drag Mode & Zero-Polling Background Optimization / 桌面格言 Alt + 拖拽与零轮询休眠
- **Interaction Consistency (交互体验完全统一)**：桌面格言在平时保持 100% 鼠标点击穿透（`HTTRANSPARENT`），绝不遮挡底层网页或代码；按住 `Alt` 键（或从托盘点击“调整位置”）立即可交互（`HTCLIENT`），浮现微交互圆角卡片、操作按钮（换一句、固定、关闭）与右侧拉宽手势。
- **Eliminated 200ms Continuous Cursor Polling (彻底移除 200ms 鼠标轮询)**：彻底移除了每秒 5 次的 `Cursor.Position` 轮询定时器。当格言固定在桌面背景时（`IsPinned == true`），定时器完全停止，实现 **0 唤醒、0% CPU 占用与零内存分配**。
- **Settings Tab 1 Tip Refinement (设置界面底部操作提示与样式统一)**：Tab 1 底部提示文字优化为 `提示：在桌面格言文字上按住 Alt + 拖拽调整位置，拖动右边缘调节宽度，Alt + Ctrl + 滚轮缩放字号。`，关键词（`Alt + 拖拽` 与 `Alt + Ctrl + 滚轮`）以 **蓝色斜体** 醒目渲染，支持依据宽度的智能断句自适应换行。

### ✉️ About Dialog Author Email & Feedback Channel / 关于页面新增作者邮箱与即时反馈
- **Direct Author Communication**: 在关于对话框中加入作者直连邮箱 `francodeyvison183@gmail.com`，采用居中两行现代排版。
- **One-Click Copy & Mail Client Trigger**: 点击即可自动复制邮箱地址到系统剪贴板并弹出 2 秒原生微提示（`✓ 邮箱地址已复制到剪贴板！` / `✓ Email copied to clipboard!`），同时调起默认邮件客户端。

### 🛡️ Fix Tray Scroll Wheel Hijacking Running Countdown / 修复托盘启动倒计时后滚轮意外篡改时间缺陷
- 解决了低级鼠标钩子在用户鼠标移出托盘进入工作区时可能意外拦截全局滚轮导致倒计时时间被修改的问题。
- 增加了严格的状态守卫机制：倒计时进行中严禁挂载时长调节钩子，鼠标进入桌面工作区立即释放钩子，彻底杜绝干扰。

### 📐 Desktop Quote Default Horizontal Centering & Decoupling / 桌面格言默认水平居中与坐标解耦
- 解耦了格言 X 轴与 Y 轴的自适应逻辑，默认水平居中于屏幕中轴线（与倒计时文字对齐），纵向保持在 `Y = 120px` 优雅居中，字号或文字长度变化时自动重新居中。

### ✨ AI Agent Quote Expansion / 每日格言 AI 智能体 MCP 极简自动扩充
- 设置面板 Tab 1 新增并排 `[ 自定义… ]` 与 `[ ✨ AI 扩充 ]` 按钮。
- 全新极简 410 × 265px 扩充面板，采用标签池体系，单次精选扩充 **30 条** 高质量名言。
- 独创 **双轨就地执行与实时汇报反馈体系**（命令行直接执行轨 + IDE 对话框协作轨），扩充完成后就地汇报成果卡片，并自动去重与写入 `.bak` 备份。

### 🤖 Native MCP (Model Context Protocol) Server (`iclock.com --mcp`) / 智能体标准协议服务
- 内置基于 JSON-RPC 2.0 stdio 的原生 MCP 服务器，零外部第三方依赖。
- 提供 5 大原生 MCP 工具：
  - **`iclock_ask_human`** (Desktop Decision Gate / 桌面决策请示门禁)：AI 执行高危操作（删库、发布、付费 API）前在桌面唤起置顶阻断卡片获取人类确认，支持按键直达、自由文本输入、智能前后台感知与免打扰。
  - **`iclock_timer`**：联动倒计时，启停或调整专注计时。
  - **`iclock_notify`**：任务完成桌面全向弹窗与声音唤醒。
  - **`iclock_quote`**：在桌面投射便签、阶段性思考或当前状态。
  - **`iclock_status`**：感知当前专注状态与剩余时间。
- 终端运行 `iclock --mcp-prompt` 或在设置界面一键复制接入提示词，让智能体自主完成配置。
