# iClock 1.01 for Windows

Download **`iClock-1.01-windows.zip`** (or standalone **`iClock-1.01-windows.exe`**), extract it, and run `iClock.exe`. No installer or administrator privileges are needed.

## What's Changed

- **Default Font Size**: Adjusted default countdown overlay font size to `20` px for a cleaner desktop footprint.
- **Default Font Color**: Adjusted default countdown color to Red (`#FF0000`) for enhanced contrast against bright wallpapers.
- **Bilingual Official Site**: Updated documentation, release packages, and official site with instant Chinese/English toggles.

## Requirements

- Windows 10 or Windows 11 (also supports Windows 7 SP1 / 8)
- .NET Framework 4.x
