## 🌟 What's New in v1.10 / 主要更新内容

### ✨ AI Collaboration Page Revamp / AI 协作页重构
- **Value-First Narrative (价值先行叙事)**：协作页按"价值 → 总开关 → 安装技能"的顺序重排，先告诉你 AI 协作能做什么（决策请示/任务状态/完成提醒），再给总开关，最后才是按智能体安装技能。
- **Per-Agent Skill Install (按智能体独立安装)**：技能按 Agent 独立安装到各自目录（Codex → `~/.codex/skills`，Cursor → `~/.cursor/skills`，Claude → `~/.claude/skills`，Antigravity → `~/.gemini/antigravity-cli/skills`，Windsurf / Copilot 等同理，其余走 `~/.agents/skills` 兜底），安装状态互不影响。
- **Running-Only Agent List (仅列运行中的智能体)**：技能卡只列当前检测到的运行中 Agent，按钮兼作状态指示（未装 = `安装技能`，已装 = `已安装 ✓` 置灰），配合指纹比对实现零闪烁刷新。
- **Install Failure Closed-Loop (安装失败闭环)**：失败时展示具体原因 + 按错误类型匹配的人类指引 + `重试` / `覆盖安装` / `复制修复指令`，修复指令自动带上当前 Agent 的目标路径，可粘贴给任意智能体让它自己解决。

### 🎯 Minimal Task Status HUD / 极简任务状态浮层
- **Strip the Chrome (去除卡片外壳)**：不再渲染 Agent 名称、百分比、圆角灰底与边框，只剩半透明进度条 + 一行消息，文字颜色跟随桌面格言。
- **Layered Window (真正的分层窗口)**：改用 `UpdateLayeredWindow` 渲染，支持真正的 per-pixel alpha，进度条轨道与填充都是半透明。
- **Alt-Driven Editing (Alt 驱动的编辑模式)**：
  - `Alt + 拖中部` 移动位置，带屏幕竖直中线吸附和蓝色虚线参考线；
  - `Alt + 拖右边缘` 调整宽度（160–800px，自动保存）；
  - `Ctrl + Alt + 滚轮` 调整字号（7–16pt，自动保存）；
  - `Alt + 点右上角色板` 分别改文字色 / 进度条色（自动保存）。
- **Alt Hover Card (Alt 悬停卡)**：按住 Alt 时浮层显示 20% 透明深底圆角卡 + 浅色边框，与桌面格言的悬停视觉一致；Alt 松开即恢复极简模式。
- **Defer Clear While Tweaking (调整期间延迟清除)**：Alt 按住期间收到的清除指令会被暂存，直到 Alt 松开后 60 秒才真正清除，避免调色/调位置时 HUD 突然消失。

### 📝 AI Quote Expansion Dialog / AI 扩充名言对话框
- **Free-Form Preference (自由偏好输入)**：偏好标签从"标签药丸 + 添加输入框"改为多行文本框，既支持逗号/换行分隔的关键词，也支持整段自然语言描述，老配置平滑迁移。
- **Count Input (数量可调)**：新增"扩充数量" `NumericUpDown`，范围 5–100、步进 5、默认 30，Prompt 中的数量全部参数化，文案与实际请求始终一致。

### 📖 Daily Quote Persistence / 每日格言持久化
- **Same-Day Consistency (同日一致)**：今日所选格言会被记住（`QuoteIndex` + `QuoteDate` 持久化），设置页打开预览、桌面翻页、重启后，看到的都是同一条格言，不再靠种子随机重排。
- **Day Rollover Advance (跳天自动前进)**：新的一天从昨日格言的下一条开始，连续翻阅不会重复昨天的内容；首次使用仍按日期种子分布。

### 🎨 Quote Color Palette Independence / 格言颜色独立色板
- **Warm Orange Default (暖橙默认)**：格言颜色默认从“跟随倒计时”解耦，改为独立默认色 **暖橙 `#F77F00`**，未设置时不再随倒计时色变，视觉上也与倒计时红拉开层次。
- **Dedicated Palette (独立色板)**：格言色板不再复用倒计时的 9 色，新增 8 个更柔和的预设：暖橙 (默认) / 柔白 / 雾灰蓝 / 暖杏 / 豆沙绿 / 藕粉 / 燕麦 / 暮蓝 / 自选；倒计时的经典红 9 色板保持不变，两处配色互不影响。
- **Task HUD Follows Quote (任务浮层跟随格言色)**：任务状态浮层文字颜色在未单独设置时默认取暖橙，与格言配色保持一致。

### ✅ Collaboration Page: Two Install Methods / 协作页：两种启用方式
- **Method 1 · Install Skill (方式一 · 安装技能)**：持久有效，按运行中的 Agent 一键安装技能。
- **Method 2 · Temporary Enable (方式二 · 临时启用)**：新增独立卡片，一键`复制指引`发给当前会话的智能体，无需安装即可本次会话通过 iClock 提醒重要进展；原来藏在空状态里的 LinkLabel 入口升级为常驻卡片。
- **Cleaner Agent Rows (Agent 行更清爽)**：运行检测点改为 8×8 实心圆点（任意 DPI 下渲染一致），`安装技能` 按钮改为无边框纯色（蓝色 hover 加深），行间有分隔线，“已安装 ✓” 置灰；空状态文案不再混入临时启用入口（已挪到方式二卡片）。

### 🎨 Misc / 其他
- **Self-Check Updated (自检同步)**：内置自检覆盖新增的两种启用方式与格言持久化。
