## 🌟 What's New in v1.15 / 主要更新内容

> v1.15 的主题是**「逆向级状态感知」**：对 8 家主流智能体做了一轮系统性逆向工程（`rea/` 目录留档），把状态栏从「读转录日志」升级为「读智能体自己的注册表 / 心跳 / worker 通道」，并按活跃会话的真实样本逐一校准了状态语义。

### 🔬 逆向工程驱动的状态感知 (Reverse-Engineered State Sensing)

- **Claude Code：注册表 + 桌面壳双通道**：除了读项目转录，新增轮询 `~/.claude/sessions/<pid>.json` 进程注册表（`status` 字段经活跃会话校准，运行态枚举实测为 **`busy`**），以及桌面壳 `waiting-input` 目录（等待人工输入时立即弹出 ❓ 胶囊）。
- **Cursor：项目级 worker 存活检测**：新增 `SyncCursorLiveState`，从 `agent-cli-state.json` 读出项目↔worker 映射，再解析每个 worker 日志头部提取 `workerId` / `workspacePath`，**按项目精确判定在线**——多项目并行时一个 worker 退出只清理自己项目的胶囊，不再互相干扰。
- **WorkBuddy：心跳注册表**：`~/.workbuddy[-ai]/sessions/<pid>.json` 的 `lastHeartbeat` ≤15 秒判定会话在线，过期或进程死亡立即清理。
- **ZCode / Kimi Code：首次接入**：ZCode 轮询 `~/.zcode/v2/logs` 宿主日志的 `bots.runningTasks` / `agent.pendingUserInputs` 计数；Kimi 监听 `~/.kimi-code/sessions/**/wire.jsonl` 的活跃写入，会话在线立即感知。
- **OpenCode：首次接入**：逆向发现其权威状态源是 `opencode.db`（SQLite，`step-start` / `step-finish(reason=stop|tool-calls)` 完整生命周期），v1 用 `opencode.db-wal` 活跃锚点 + 进程存活做宿主级在线检测，并配了专属徽章色。

### ✅ 按真实会话样本校准的状态语义 (Calibrated Against Live Sessions)

- **Codex**：`task_started` / `task_complete` / `turn_aborted` 生命周期按活跃 rollout 文件逐字段确认——`task_complete.last_agent_message` 作为完成摘要，`turn_aborted(reason=interrupted)` 不再渲染成错误。
- **Antigravity**：实证修正 `GENERIC status=ERROR` 的语义——它是**步骤级错误**（工具调用失败后智能体自我恢复继续执行），不是整轮终止；只有 `ERROR_MESSAGE` 才渲染为异常。
- **Cursor**：`turn_ended.status` 全集实测仅 `success` / `error` 两种，显式映射完成/异常。
- **不再基于猜测**：ZCode 计数语义、Kimi 事件行、Claude 运行态枚举等尚未拿到活跃样本的映射，在逆向文档中明确标注「未校准」，代码采用保守策略，不误报。

### 🛡 路径韧性 (Path Resilience)

- **多根探根**：候选数据根从单一 `USERPROFILE` 扩展为 `USERPROFILE` → `HOMEDRIVE\HOMEPATH` → 运行中进程的 exe 目录反推，主目录重定向、便携版安装都能自动命中。
- **Cursor worker 便携路径**：除了 `%APPDATA%`，还会探测 Cursor 便携版 exe 旁的 `user-data` 目录。

### 🔧 稳定性修复 (Stability Fixes)

- **WorkBuddy 胶囊残留**：注册表文件被删除时立即清理状态条，不再等 5 分钟过期。
- **Kimi 路径**：候选根从 `~/.kimicode`（slug  stripping 误伤）修正为真实的 `~/.kimi-code`。
- **GDI 与计时器泄漏**：长时间常驻后句柄数不再缓慢爬升。
- **开机自启自愈**：每 60 秒检查一次注册表 Run 键，被清理后自动重写。
- **HUD 细节**：Antigravity 步骤信封不再污染 GENERIC 结果；自动会话标题不进状态条标题；钉住的条不再复活已结束任务；等待/错误态任务不受 5 分钟静默过期影响。
