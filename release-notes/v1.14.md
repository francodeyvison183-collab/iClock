## 🌟 What's New in v1.14 / 主要更新内容

> v1.14 是一次**大版本**：智能体状态条从「窗口标题猜测」升级为「读取智能体自己的会话记录」，用时统计从「可选开关」变成「默认开启并新增趋势视图」，源码从单个 6400 行文件拆成 16 个功能模块。

### 🤖 多智能体统一状态条 (Unified Multi-Agent HUD)

- **一条状态条装下所有智能体**：多个智能体同时在跑时，桌面顶部只有一条状态条，胶囊药丸按「等待 / 错误 > 运行中 > 已完成」的优先级动态排序，5 秒固定节奏轮播最相关的那一个。
- **同智能体多会话不再混淆**：同一个智能体开多个会话时，药丸自动编号 `#1`、`#2`，编号由会话键的字典序稳定派生，重绘时不会跳号。
- **可展开的智能体列表与可调高度**：状态条高度可以拖动调整，智能体列表可展开查看全部在线智能体。
- **置顶与锁定**：悬停状态条会出现图钉图标，钉住后状态条常驻桌面，不会因为会话结束或超时被自动清掉。
- **顶部居中 + 5 秒淡出**：状态条默认停在屏幕顶部居中，前台窗口切换时淡出，完成任务后有 5 秒去抖延迟再消失。
- **拖到屏幕中央附近会出现竖向虚线吸附参考线**，方便对齐。
- **文字渲染换成 AntiAliasGridFit**，边缘细腻；同时修掉了 90 秒无脑轮询的看门狗。

### 🎯 100% 真实的智能体状态流 (Authentic Agent Stream)

- **不再有「合成词」**：过去状态条里的部分提示词是程序自己拼出来的，现在全部来自智能体自己写在会话记录里的真实内容——任务、思考、命令，一句不改。
- **直接读智能体的会话记录**：新增协议级解析器，直接读取 Claude Code、OpenAI Codex、Antigravity、Cursor 的本地会话文件，按各自协议还原「正在做什么 / 想什么 / 跑了哪条命令」。
- **零分配 JSON 扫描器**：解析热路径用自写的键值嗅探器，绕开整份 JSON 反序列化，长时间监听不产生垃圾回收压力。
- **一条记录里的多条命令按顺序全部显示**，不会只留最后一条。
- **规划与思考阶段有三点动画**，智能体最小化后状态条依然跟随最新步骤。
- **进程引导的懒监听**：只有在对应智能体进程真的在运行时才去挂载监听器，避免无谓的文件句柄与 CPU 占用。

### 👁 护眼提醒 (Eye-Care Reminder)

- 倒计时设置页新增「护眼提醒」下拉，一个下拉同时管开关与间隔，节奏与「结束声音」一致。
- 每 30 秒采样一次系统最后输入时间；连续 3 分钟没有任何输入视为一次真正的休息，累计清零。
- 休息倒计时期间不计时；全屏游戏或设置窗口打开时先不弹卡，等回到普通窗口再提醒。
- 提醒复用统一的提醒弹窗，旁边有 ⓘ 悬停说明。

### 📊 用时统计：默认开启 + 趋势视图 (Always-On Usage Tracking & Trends)

- **开关取消**：用时统计改为始终开启，只记录进程名与时长，不碰任何内容。
- **人的视角**：单日明细顶部汇总从「应用排名」升级为「在座 / 操作 / 未操作 / 离开」四段画像，操作时间再按输入强度分成重操作与轻操作。
- **新增趋势视图**：今日记录多一个「趋势」页签，上半部分是「屏幕活跃 vs 专注」双序列日对比图，下半部分是窗口内的应用排行，范围可选本周或最近 30 天。
- **点色带切换活动窗口 / 全天**：在今日记录色带上点击一次即可在「活动窗口」与「全天」之间切换，窗口起点对齐当天第一条真实记录。
- 应用颜色分配时色相自动滑动，相似名字的应用不再共用几乎一样的颜色。

### 🖥️ 命令行入口重做 (CLI Console Entry)

- **伴生 `iclock.com` 控制台程序**：裸输入 `iclock` 会把命令原样透传给正在运行的 iClock，退出码同步返回，终端提示符不再错位。
- **新增 `--status` 命令**：智能体可以用 `-st` 更新状态条上的文字，并带上 `--detail`、`--progress`、`--thinking`、`--done`、`--waiting`、`--error`、`--agent-name`、`--project` 等修饰符。
- 智能体窗口前置检测更稳，临时启动的重复进程不再误判。

### 🧱 源码模块化重构 (Modular Refactor)

- 单个 6400 行的 `iClock.cs` 拆成 16 个功能模块：`AgentHud`、`AgentWatcher`、`AgentTranscriptParse`、`Usage`、`Dialogs`、`SettingsDialog`、`Overlay`、`Quotes`、`Screensaver`、`EyeCare`、`Menu`、`Core`、`Controls`、`WelcomeAbout`、`CliLauncher`。
- HUD 的 GDI 句柄缓存化、内存 LOH 抖动消除、工作集整理，常驻内存稳在 **10 MB 以内**。

### 🎨 界面细节 (UI Details)

- 休息倒计时的文字前缀换成系统 `☕` 字形，画在数字正上方，固定暖棕色不跟随倒计时颜色。
- 每日金句不再带弯引号。
- 设置页倒计时行高收紧到 36 像素，弹窗高度保持不变。
- 今日记录列宽等宽分布，弹窗尺寸锁定。
- 所有强提醒统一收敛到同一个提醒弹窗，文字自适应 2–3 行、超长自动省略号、悬停可看全文。
