## 🌟 What's New in v1.08 / 主要更新内容

### 🖱️ Tray Double-Click Debounce & Zero False Triggers / 托盘双击防抖与倒计时零误触
- **Debounced Tray Single-Click (单击智能防抖)**：左键单击托盘图标时引入极短防抖窗口（约 200~250ms），确保双击打开设置面板时绝不意外触发倒计时的启动或暂停。
- **Instant Double-Click Cancellation (双击即时取消)**：双击托盘图标即刻中止待执行的单击倒计时切换，并开启设置窗口，彻底消除了 Windows 原生 NotifyIcon `MouseClick` 与 `DoubleClick` 事件先后的固有竞态。

### 🤖 Flash Approval HUD & Hairline Progress HUD / 智能体决策请示卡与发丝进度条
- **Enhanced Ask Human Dialog (决策请示卡醒目度升级)**：卡片采用左侧 3.5px 强调条，问题文字调整至 10.5pt 醒目排版，选项采用卡片单选行结构，原生贴合 Win11 Fluent 视觉语言。
- **Desktop Note Projection Optimization (桌面便签投射状态保护)**：投射便签始终保持 TopMost 置顶与互斥，支持智能体进程退出联动清理；并在设置界面切换到“每日格言”时，智能抑制预览格言，彻底杜绝多层重叠显示。
- **Sequential Numbering for AI Quote Expansion (格言自动递增编号)**：修复了 AI 扩充格言时自动补全并顺延历史格言最大序号，排版规范有序。
- **Desktop Quote Text Stability (切换设置标签格言稳定性)**：在桌面的设置面板切换到“每日格言”标签页时，不再篡改当前屏幕正在显示的桌面格言文本。

### 🔔 Rich Synthesized Chimes / 多样化原生合成音效
- **Door Knock Chime (拟真敲门声)**：新增“咚咚咚，咚咚咚，咚咚咚”三组富有节奏的原生物理共振木门敲击音效，排在醒目闹铃前供用户选用。
- **Dedicated AI Collaboration Chime (AI 协作专属温和提示音)**：为智能体长任务完成提供专属纯净上升和弦提示音，并原生回落支持系统 `Speech On.wav`，有效区分于专注倒计时结束闹铃。
- **Doorbell Chime (叮咚门铃声)**：三组清脆叮咚双音节和弦门铃声，提供更舒适的专注提醒体验。

### ⚡ Extreme Performance & Zero-GC Win32 Architecture / 极致性能与内存平稳优化
- **Eliminated Sawtooth Wave (消除内存锯齿波动)**：移除了高频 `EmptyWorkingSet` 与大面积 `Process` 枚举开销，使用轻量化 Win32 原生 API，极大降低 GC 压力，实现 0.0% CPU 占用与稳如磐石的低内存表现。
- **Control Layout Thrashing Optimization (控件重绘防抖)**：优化设置面板智能体列表与 MCP 模块的绘制逻辑，保证标签切换瞬间丝滑无卡顿。
