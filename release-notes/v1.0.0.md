# iClock 1.0.0 for Windows

Download **`iClock-1.0.0-windows.zip`**, extract it, and run `iClock.exe`. No installer or administrator privileges are needed. The ZIP also contains a quick-start guide and the MIT License.

## Requirements

- Windows 10 or Windows 11
- .NET Framework 4.x

## Included

- `iClock.exe` — the application
- `README.txt` — quick-start instructions
- `LICENSE.txt` — MIT License

The executable is about 27 KB. The package does not bundle the .NET Framework runtime. See the repository README for source code, build instructions, and the full changelog.

The tray menu includes a language selector for Simplified Chinese and English. Simplified Chinese is selected by default.
