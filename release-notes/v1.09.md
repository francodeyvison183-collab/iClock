## 🌟 What's New in v1.09 / 主要更新内容

### ⚙️ Canonical Settings & Instant Apply / 设置单一数据源与即改即生效
- **Single Source of Truth (单一数据源)**：设置面板直接编辑运行时唯一的 `Settings` 实例，全面移除草稿副本、预览副本与隐藏的保存/取消按钮，任何修改立即作用于悬浮时钟与桌面格言，彻底消除"面板显示值"与"实际运行值"不一致的结构性隐患。
- **Persistent Quote State on Exit (退出前状态持久化)**：关闭设置或退出程序前，先捕获桌面格言的真实屏幕位置、宽度与字号再落盘，避免预览/关闭路径覆盖用户最新调整。

### 🖥️ Multi-Monitor Desktop Quote Restore / 多屏桌面格言位置恢复
- **Cold Restore on Secondary Monitors (副屏冷启动坐标恢复)**：格言窗口冷启动即恢复保存的位置、宽度与字号，含负坐标副屏布局。
- **First-Visible Geometry Sync (首帧几何同步)**：首次可见渲染执行原生分层窗口边界同步，消除亮相瞬间的跳动。
- **Idempotent Refresh (幂等刷新)**：`NextQuote` 与设置页切换均保持已保存坐标不变；显示器断开时依旧优雅回退到主屏。
- **Hidden Instance Restoration (隐藏实例恢复)**：被隐藏的常驻格言实例不再被误判为"正在显示"，开机/解锁唤醒路径可正常恢复。

### 🔌 Structured MCP Tool Responses / MCP 工具结构化 JSON 响应
- **Machine-Readable Results (机器可读返回)**：6 个 MCP 工具全部返回结构化 JSON（`status` / `action` / `message` 等），智能体可编程区分成功、取消与超时。
- **Richer Ask Human Semantics (决策门禁语义增强)**：`iclock_ask_human` 新增 `action: "cancel"` 与 `cancelled` / `timed_out` 字段，`question` 不再必填。
- **Tool Surface Cleanup (工具面收敛)**：`iclock_quote` 新增 `clear` / `hide` 清除便签投射；`iclock_progress` 校验百分比/分数/小数格式并拒绝非法输入；`iclock_notify` 支持 `agent_name`。

### 🧪 Regression Suite Hardening / 回归测试强化
- **SelfCheck Expansion (自检覆盖扩展)**：覆盖单一数据源设置、热键可用性标记、格言状态捕获、隐藏实例恢复与副屏坐标保持，45 项全部通过。
- **New Multi-Monitor Suite (新增多屏专项)**：`tests/QuoteLayoutCheck.cs` 由 `build.ps1` 自动编译，守护冷启动恢复、首帧几何、设置刷新稳定性与断屏回退。
