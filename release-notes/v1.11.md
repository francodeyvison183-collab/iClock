## 🌟 What's New in v1.11 / 主要更新内容

### 🖥️ 每日金句屏保 (Daily Quotes Screensaver)
- **注册为系统屏保 (Register as the Windows screensaver)**：iClock 现在可以把自己注册为 Windows 屏保，全屏显示当天的金句。设置页金句分区改为「总开关在最前」，屏保开关是一个独立开关（**默认关闭**），空闲等待时间收进页面里的下拉框——右键开关即可选 1 / 5 / 10 / 15 / 30 分钟。
- **Windows 真正读取的键值 (The value Windows actually reads)**：等待时间同时写入 `SCRNSAVE.EXE` 与注册表，`/s` 启动会记进 `saver.log`，Windows 侧启动异常时可以直接查日志定位。
- **预览即所得 (WYSIWYG Preview)**：新增「预览」按钮直接拉起真正的屏保（鼠标移动或 Esc 退出），所见即所得，不用再拿「长得像」的去比对。
- **跟随时钟与排版 (Follows the quote settings)**：屏保沿用设置里配置的金句字号，文本块以屏幕高度 38% 为中心锚定（预览与实跑一致），纯黑底只画文字、不再套卡片边框，并叠一个 32px 品牌标记（图标下方一层柔和的强调色光晕）。

### ✨ AI 扩充金句：一段指令，任意智能体 (One Instruction, Any Agent)
- **不再挑智能体 (No agent picker)**：扩充弹窗不再列出或选择智能体，只负责生成指令、复制到剪贴板并等待入库——导入仍由你正在用的那个智能体执行 `iClock --quote-add` 命令行完成，与此前完全一致。
- **界面收紧到 380 × 280 (Tightened to 380 × 280)**：偏好输入、数量（5–100）、复制指令、等待入库、完成五个状态压进一张 380 × 280 的小窗，等待视图把「粘贴发送 → 命令行导入 → 完成汇报」三步写清楚。
- **更干净的状态说明 (Cleaner status line)**：原先那行「AI 协作智能体」标签和下拉框一并撤掉（它们是旧逻辑残留，与实际扩充流程无关），提示行改写为状态说明。

### 🏷️ 每日格言 → 每日金句 (Daily Quotes renamed to Daily Golden Lines)
- 界面中文统一改用「每日金句」（设置页、桌面开关、屏保行、提示文案、AI 扩充提示），桌面开关不再带「便签」后缀；AI 扩充提示要求智能体按 `金句内容 | 作者或出处` 输出。英文界面保持 "Daily Quotes"。

### ⏱️ 倒计时结束的休息时长终于能选了 (The Rest Length Is Selectable Now)
- 结束弹窗里的「休息 N 分钟」按钮原本把 ▼ 画在文字里，而可点区域只有最右侧 24px——**可见的箭头落在可点区之外**，菜单几乎点不中，点「休息 10 分钟」这几个字反而直接开始休息。
- 现在箭头独占一块 36px 的绘制区域（有细分隔线、悬停高亮），文字在剩余空间居中；菜单用 ✓ 标出当前时长；点击区域改由「按下位置」判定，不再依赖框架触发 Click / MouseClick 的顺序。

### 🧹 更少的遗留逻辑 (Less Legacy)
- 删掉「让 iClock 自己去跑智能体」的无头链路（iClock 不再 spawn `claude -p` / `ollama run`，那条路径本来也只会卡在 35 秒超时）、智能体下拉框与运行态列表、「唤起窗口」辅助，以及 `AiAgentType` / `AiAgentCustomCmd` 配置项。设置页智能体分区的列表保持不变——它属于技能安装。
- 同时移除了 iClock MCP 服务端及其智能体侧工具/配置流程，桌面协同统一走带 `--json` 结构化响应的命令行；已有的智能体 MCP 配置项不会自动改动或删除。
