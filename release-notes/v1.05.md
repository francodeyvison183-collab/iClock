## 🌟 What's New in v1.05 / 主要更新内容

### 💻 CLI & Script IPC Pipeline (`WM_COPYDATA`) / 命令行与脚本联动
- **Zero-Latency Win32 IPC Pipeline**: Second invocations from terminal seamlessly communicate with the running background iClock instance via native Win32 `WM_COPYDATA` (0x004A) messages.
- **Global Invocations without `.exe`**: Run `iclock --install-cli` once to register into User PATH, enabling direct global usage in any terminal (`iclock -s 25`, `-p`, `-r`, `-t`, `--reset`, `--rest`, `-n <message>`) just like `claude` or `pi`.
- **Script Notifications**: Easily hook into CI/build commands (`npm run build && iclock -n "Build Done"`) to trigger desktop popups and chime alerts.
- **Dedicated Minimalist Notification Card (`CliNoticeDialog`)**: Custom-tailored notification card for CLI-triggered alerts featuring the high-DPI vector iClock squircle logo, prominent message typography, and a single keyboard-dismissible `[我知道了]` button.


### 🎨 Brand New Application Icon & Multi-Resolution Asset Set / 全新品牌图标体系
- **Modern Minimalist Visual Identity**: Introduced a high-contrast deep navy squircle (`#131C43`) with transparent antialiased rounded corners, pure white "i", and a vibrant coral orange slash (`#FF5738`).
- **Pristine Dark & Light Taskbar Legibility**: Tested and calibrated to provide exceptional contrast and crisp legibility on both dark and light Windows desktop themes.
- **Master Multi-Resolution Archive (`src/icons/`)**: Preserved the complete 9-resolution lossless PNG assets (16×16, 20×20, 24×24, 32×32, 40×40, 48×48, 64×64, 128×128, 256×256, 512×512) alongside a comprehensive documentation guide.
- **Native GDI+ Compatibility Fix**: Resolved the legacy Windows GDI+ `Icon.ToBitmap()` rainbow noise glitch by generating compliant 32bpp DIB layers and procedural vector fallbacks.

### ⚡ Extreme Binary Size Optimization (160 KB) / 极致体积精简
- **De-bloated Runtime Executable**: Decoupled design assets from binary compilation by streamlining the embedded icon to an uncompressed 24×24 DIB sweet-spot and downsampling the sponsor QR asset to 450×450 high-fidelity bicubic JPEG, dropping the final executable size from 505 KB to an ultra-compact **160 KB** (163,840 raw bytes, down by nearly 70%).
- **Zero Heavy Runtime Bloat**: Pure native C# / GDI+ architecture with zero Electron or Chromium dependencies.

### 📐 Optical Calibration for Pause Badge / 暂停微标光学垂直居中
- **Subpixel Optical Alignment**: Resolved the typographic baseline offset where digits (`25:00`) visually sat lower than the geometric window center.
- **Zero-Offset Center**: Precomputes true character bounding boxes via `GraphicsPath.AddString` so the pause indicator (`❚❚`) and countdown digits share the exact same optical center line ($0.0\text{px}$ measured offset).
- **Refined Aspect Ratio**: Tuned pause bar height to 72% of actual digit height for a balanced, harmonious look.

### 🧪 Live Preview & "Test Alert" Button / 设置实时预览与测试提醒
- **Live Screen Preview**: Adjusting font family, font size, or color in the Settings dialog instantly reflects on the active screen overlay in real-time.
- **Interactive "Test Alert" (测试提醒演示)**: Added a dedicated test button in both Timer and Agent Collaboration tabs to immediately experience chosen alarm sounds, popup notices, or breathing pulse animations without waiting for timers.

### 🤖 Smart Agent Priority Sorting & Performance Tuning / 智能体排序与性能飞跃
- **Running Agents Priority**: In the Agent Collaboration tab, currently running / busy AI agents are automatically sorted to the top of the card list for instant status inspection.
- **Dynamic Toast Scan Throttling**: Reduced WinRT Toast listener polling frequency when idle, significantly lowering background CPU cycles.
- **Smart Mouse Hook Lifespan**: Automatically detaches system mouse hooks after tray hover inactivity, saving CPU interrupts.
- **Proactive Memory Compaction (`TrimMemory`)**: Closes dialogs with immediate process working-set trimming to keep memory footprint exceptionally lean (~10-18 MB working set).
