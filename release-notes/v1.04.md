# iClock 1.04 for Windows

Download **`iClock-1.04-windows.zip`** (or standalone **`iClock-1.04-windows.exe`**), extract it, and run `iClock.exe`. No installer or administrator privileges are needed.

## What's Changed

- **AI Agent Background Task Completion Alerts (Plan B-1)**: Automatically monitors 20+ domestic & international AI coding assistants and CLI agents (Cursor, Antigravity, Claude Code, GitHub Copilot, Trae, Tongyi Lingma, CodeGeeX, Baidu Comate, MiniMax, CodeBuddy, Aider, Cline, etc.).
- **4-Tier Perception Engine (四级全向感知矩阵)**:
  - 🥇 **Tier 1 (WinRT Toast Notification Listener)**: Real-time listener for system toast alerts with 0ms latency, rich task summary display, and 0% false positives.
  - 🥈 **Tier 2 (Win32 Shell Hook Taskbar Flashing)**: `RegisterShellHookWindow` + `HSHELL_FLASH` capturing background IDE/terminal completion flashes with 0ms latency and 0.0% CPU overhead.
  - 🥉 **Tier 3 (Terminal & Window Title Dynamics)**: State machine monitoring window titles and status badges (`[Running]`, `Thinking...`, `●`), firing instantly when returning to idle.
  - 🛡️ **Tier 4 (High-Threshold Cluster CPU Fallback)**: Multi-process aggregated CPU edge detector with enhanced guard thresholds (≥5s heavy burst, ≥6s continuous quiet, 30s cooldown debounce) to prevent false triggers during multi-step tool pauses.
- **One-Click Window Restore**: Clicking "View / 查看" on any completion alert immediately restores and activates the corresponding AI agent window.
- **Settings Dialog Modern Dual Tabs (Plan B-1)**: Segmented dual-tab navigation (⏱ Timer / 🤖 AI Agent Collaboration) cleanly displaying only detected active/ready agents with 1-click real-time re-scan.
- **Native 32-bit ARGB Layered Window Rendering**: Replaced colorkey rendering with native `UpdateLayeredWindow`, delivering pristine subpixel anti-aliasing and adaptive soft drop shadows across light/dark desktop environments.
- **Direct Ergonomic Alt+Drag Positioning**: Hold `Alt` and left-click drag the floating digits anywhere on the desktop to reposition instantly, with automatic coordinate persistence.
- **Tray Scroll Wheel Micro-Tuning**: Hover over the tray icon to roll mouse wheel for fast duration tuning (`±1m`, or `±5m` with `Shift`), with direct wheel support over the floating clock while holding `Alt`.
- **Tiered Alerts & Auto Fullscreen DND**: Choose between TopMost Popup Alert and subtle In-Place Breathing Pulse; automatically downgrades popups to silent breathing pulse during full-screen games, PPT slideshows, or video playback.
- **Comprehensive Focus History & Multi-Day Statistics**: Daily Details view with sequence numbers and actual duration, plus Days Summary view tracking streaks across 7/14/30 days with completion rates, evaluations, double-click drill-down, and `Ctrl+C` clipboard export.
- **System Architecture & Robustness**: Atomic configuration saving (`File.Replace`), centralized Win32 interop (`NativeMethods`), kernel handle leak prevention (`SafeProcessHandle`), and multi-monitor disconnect auto-recovery.

## Requirements

- Windows 10 or Windows 11 (also supports Windows 7 SP1 / 8)
- .NET Framework 4.x
