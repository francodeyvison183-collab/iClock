## 🌟 What's New in v1.04 / 主要更新内容

### 🤖 AI Agent Background Task Monitor / AI 智能体长任务完成监控
- **20+ Domestic & International AI Agents Covered**: Automatically detects and monitors **Cursor, Antigravity, Claude Code, GitHub Copilot, Trae, Tongyi Lingma (通义灵码), CodeGeeX, Baidu Comate (文心快码), MiniMax, CodeBuddy, Aider, Cline**, and other CLI/IDE assistants.
- **4-Tier Perception Engine (四级全向感知矩阵)**:
  - 🥇 **Tier 1 (WinRT Toast Notification Listener)**: Zero-latency listener for system toast alerts with rich task prompt extraction and 0% false positives.
  - 🥈 **Tier 2 (Win32 Shell Hook Taskbar Flashing)**: `RegisterShellHookWindow` + `HSHELL_FLASH` capturing background terminal/IDE taskbar completion flashes with 0ms latency and 0.0% CPU overhead.
  - 🥉 **Tier 3 (Terminal & Window Title Dynamics)**: State machine monitoring window titles and status badges (`[Running]`, `Thinking...`, `●`), firing instantly when returning to idle.
  - 🛡️ **Tier 4 (High-Threshold Cluster CPU Fallback)**: Multi-process aggregated CPU edge detector with enhanced guard thresholds (≥5s heavy burst, ≥6s continuous quiet, 30s cooldown debounce) to prevent false triggers during multi-step tool pauses.
- **One-Click Window Restore (一键还原窗口)**: Clicking "View / 查看" on any completion alert immediately brings the corresponding AI agent window to the foreground.
- **Modern Segmented Dual Tabs (设置双标签页)**: Cleanly separated **⏱ Timer (倒计时设置)** and **🤖 AI Agent Collaboration (AI 智能体协同)** tabs, with real-time running/ready status badges and a 1-click re-scan button.

### 🪟 Visuals & Ergonomics / 交互与渲染升级
- **Native 32-bit ARGB Layered Window Rendering**: Replaced colorkey rendering with native `UpdateLayeredWindow`, delivering pristine subpixel anti-aliasing and adaptive soft drop shadows across light/dark desktop environments.
- **Direct Ergonomic Alt+Drag Positioning**: Hold `Alt` and left-click drag the floating digits anywhere on the desktop to reposition instantly, with automatic coordinate persistence.
- **Tray Scroll Wheel Micro-Tuning**: Hover over the tray icon or floating clock (with `Alt`) to roll the mouse wheel for fast duration tuning (`±1m`, or `±5m` with `Shift`).
- **Tiered Alerts & Auto Fullscreen DND**: Choose between TopMost Popup Alert and subtle In-Place Breathing Pulse; automatically downgrades popups to silent breathing pulse during full-screen games, PPT slideshows, or video playback.
- **Comprehensive Focus History & Multi-Day Statistics**: Daily Details view with sequence numbers and actual duration, plus Days Summary view tracking streaks across 7/14/30 days with completion rates, evaluations, double-click drill-down, and `Ctrl+C` clipboard export.

### ⚡ System Architecture & Robustness / 稳定性与底层优化
- **Zero-Dependency 222 KB Executable**: Handcrafted native .NET WinForms without bulky Electron runtimes.
- **Atomic Configuration Saving**: Prevents config corruption on unexpected shutdown via `File.Replace`.
- **Centralized Win32 Interop & Safe Handle Scoping**: `NativeMethods` encapsulation and `SafeProcessHandle` to guarantee zero kernel handle leaks.
- **Multi-Monitor Disconnect Auto-Recovery**: Prevents floating window loss when displays are disconnected or resolution changes.
