# iClock 1.02 for Windows

Download **`iClock-1.02-windows.zip`** (or standalone **`iClock-1.02-windows.exe`**), extract it, and run `iClock.exe`. No installer or administrator privileges are needed.

## What's Changed

- **Refined Tray Menu Layout**: Standardized 32px horizontal padding, vertically centered menu items, crisp right-aligned shortcut indicators in distinct tertiary gray, and clear 3-state ForeColor highlights for countdown status (Start: Accent Blue, Pause: Amber, Resume: Forest Green).
- **4px Input & Dropdown Padding**: Added 4px native internal padding for all dropdown options and input box text items (countdown duration, text size, hotkey, end message) in the Settings dialog.
- **Consistent OwnerDraw Controls**: Unified owner-draw fixed item rendering across font family, display format, and UI language combo boxes.
- **Codebase Simplification**: Removed dead and deprecated legacy classes/methods, eliminated duplicate formatting utilities, and reduced binary footprint.

## Requirements

- Windows 10 or Windows 11 (also supports Windows 7 SP1 / 8)
- .NET Framework 4.x
