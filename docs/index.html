常见问题解答

即问即答
Q: 什么是置顶穿透（Click-Through）？打游戏或写代码时会影响鼠标操作吗？
基于 Windows WS_EX_TRANSPARENT 原生 API，倒计时浮层置顶在所有窗口之上，但所有鼠标点击与滚轮事件均直接穿透到底层的编辑器、终端或游戏画面，丝毫不干扰任何前台操作。
Q: 为什么体积只有 253 KB？
坚持纯粹原生。基于 Windows 内置的 .NET Framework 与 GDI+ 绘制，坚决不打包任何动辄上百兆的 Electron 或 Chromium 浏览器壳，运行内存稳定在 15 MB 以内。
Q: 桌面格言常驻后台会消耗笔记本电池吗？
完全不会。iClock 采用纯事件消息驱动与 0-Polling 架构，静止常驻时 CPU 占用为 0.0%，彻底消除了后台定时器循环唤醒，笔记本全天候常驻零耗电。
Q: 原生 MCP 服务支持哪些智能体？
内置原生 stdio MCP Server (iclock.com --mcp)，无须 Node.js 或 Python 环境，开箱支持 Claude Desktop、Cursor、Windsurf、Antigravity 等任意标准 MCP 客户端，并提供独特的 iclock_ask_human 桌面决策请示门禁。
